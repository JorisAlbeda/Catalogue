# Magician's Code

## Description

Magician's Code is a magic academy as old as the Woodland Empire itself. Its halls run colder than the outside air, lined with scrollcases whose latches have been replaced a dozen times over while the wood beneath them never has. Every archway carries a ward-line worn smooth and grey by centuries of hands touching it in passing — an old habit that has long outlived whatever the ward itself was for. It houses no throne room; its main chamber is a bare space where whoever holds the room simply stands.

## History

Currently flooded with applicants drawn by rumours of the Darkest Flame. In the 410th year of the Old Oak, Chancellor Lilith Woodborne stayed here while overseeing the reinforcement of Charming Valley's defences, and granted audience in its main chamber to Marren Wick, claimant to the vacant Truthwatcher's desk.
